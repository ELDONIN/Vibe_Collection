# GoLoT GPU

Визуализация игры «Жизнь» Конвея ~1.4 млн ячеек на 3D-торе с интерактивной камерой. Поле можно также посмотреть в виде плоской развёртки.

## Управление

### Мышь

- **Левая кнопка** — вращение тора (в виде развёртки — панорамирование)
- **Правая кнопка** — рисование живых клеток кистью
- **Средняя кнопка** — панорамирование
- **Колесо** — масштаб

### Клавиши

- **R** — сброс положения в пространстве (поворот, сдвиг, масштаб)
- **S** — включить / выключить автоматическое вращение тора
- **G** — включить / выключить просчёт новых поколений
- **D** — переключить вид: тор или развёртка на экран
