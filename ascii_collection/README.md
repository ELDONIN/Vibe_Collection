# 3D ASCII Console

ASCII-меню с трёхмерным рендерером и парой классических игр.

## Управление

### Меню
- **Стрелки** — выбрать программу
- **Enter** или клик — открыть
- **1–4** — сразу запустить пункт

### 3D-сцена
- **Стрелки** — навигация по меню/настройкам
- **M** — открыть настройки фигуры
- **ESC** — назад в меню
- **LMB** — вращение (Arcball)
- **RMB / MMB** — панорамирование
- **Колесо** — масштаб
- **Двойной клик** — сброс камеры

### Game of Life
- **LMB / RMB** — закрасить / стереть клетку
- **R** — случайное заполнение
- **DEL** — очистить поле
- **Enter** — запуск симуляции
- **E** — вернуться в редактор
- **ESC** — в меню

### Snake
- **Стрелки / WASD** — направление
- **Enter / R** — старт и рестарт
- **ESC** — в меню

### Color change
- **Вверх / вниз** — текст или фон
- **Влево / вправо** — цвет
- **ESC** — в меню
